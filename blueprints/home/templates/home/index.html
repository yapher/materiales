Predicción de propiedades de polvos coladores mediante Machine Learning

Cómo funciona

Este sistema predice propiedades de polvos coladores (mezclas usadas en la colada continua de acero) a partir de su composición química y la temperatura de proceso, usando modelos de Machine Learning entrenados sobre el dataset cargado.

  1. Entrená el modelo (puede tardar unos minutos; podés seguir usando la app mientras corre).
  2. Armá tu mezcla y obtené la predicción.
  3. Guardá la predicción en tu dataset o exportala a PDF.
